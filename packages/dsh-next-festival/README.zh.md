# dsh-next-festival

[English](./README.md) | 中文

在对话页左上角显示所选地区的下一个节日，以及还有几天。

## 效果

```
┃ 感恩节   11月26日
┃ 还有 N 天
```

- **位置**：注册成 `shell.overlay` 的独立 entry，渲染成可**随意拖动**的小浮层；松手吸附到最近的边（上／下／左／右），沿这条边可停在任意位置。位置按视口比例保存，刷新或改窗口尺寸都不会跑掉；聚焦徽标后可用方向键微调。默认右下角。它不占用 `conversation.header.leading` —— 那是 `dsh-solar-term` 已占用的 **single 槽**，再注册会互相顶掉。两个插件完全独立、互不影响。
- 第一行是下一个节日和日期；左侧竖条按类别换色：法定红、传统金、民族青、宗教紫。
- 第二行在倒计时前标出**这个节日属于哪个地区**；当天显示「就是今天」。近似日期的「约」标在日期旁，不标在倒计时旁。多选地区时，徽标仍只显示所有选中地区里最近的那一个节日。
- 悬停或用键盘聚焦徽标，可以看到该节日所属地区、全部已选地区、类别、当地日历日、时区、之后的另外两个节日（各自标出地区），以及日期为估算时的说明；同样的信息也写在无障碍标签里。
- 每 30 秒对一次表，切回窗口立即刷新，过完当天自动换到下一个节日。

## 覆盖地区

中国大陆（`cn`）、香港（`hk`）、澳门（`mo`）、台湾（`tw`）、美国（`us`）、英国（`gb`，英格兰与威尔士）、新加坡（`sg`）、马来西亚（`my`）。华人地区包含当地传统节日与民族节日；港澳台保留当地惯用名，例如「佛誕」「天后誕」「雙十節」。

## 设置在哪里

**侧栏「插件」→ 已安装 → 下一个节日 →「节日地区」**。也就是插件自己的详情页：选择器注册在 `plugins.bundle.config` 这个按包名索引的槽里，出现在插件描述与组件列表之间，而不是通用设置页。

可勾选任意多个地区后按「保存」；至少要保留一个地区。显示位置不在这个表单里：直接拖动徽标（或聚焦后用方向键微调），松手自动贴到最近的边；设置页有「恢复默认位置」按钮。所有选中地区的节日会合并后取最近的一个，所以徽标仍只显示一个节日，并标出它属于哪个地区。未保存时会显示提示，离开页面则丢弃改动；保存后用独立的状态行反馈并在几秒后消失。其它标签页改了设置会给出提示，不会静默覆盖你还没保存的选择。设置存在本浏览器的 `localStorage`：`dsh-next-festival:regions`（JSON 数组）和 `dsh-next-festival:position`（`{xRatio, yRatio, edge}`）；旧的单选地区键和旧的四角位置字符串会在首次读取时自动迁移。它们不是 profile 配置，另一个浏览器可以各选各的。徽标与选择器即时联动，同源的其它标签页也会跟着变。默认中国大陆、右下角。

## 日期怎么算

全部在 `lib/client.js` 本地计算，不联网、无依赖。

| 规则 | 例子 | 做法 |
| --- | --- | --- |
| `fixed` | 元旦、国庆、7/1、12/20、10/10、7/4、11/5 | 公历固定 |
| `lunar` | 春节、元宵、端午、中秋、佛诞、三月三、火把节 | 用 `Intl` 的 `chinese` 历反查公历日期，跳过带 `bis` 的闰月 |
| `nth` | 感恩节、母亲节、英美银行假日 | 某月第 N 个 / 最后一个星期几 |
| `easter` | 耶稣受难日、复活节星期一 | Meeus/Jones/Butcher 格里高利复活节算法加偏移 |
| `islamic` | 开斋节、古尔邦节、Hari Raya Puasa / Haji | `Intl` 的 `islamic-umalqura` 历，标为估算 |
| `solar` | 清明、冬至 | 低精度太阳黄经求解 |
| `table` | 藏历新年、雪顿节、屠妖节、卫塞节、大宝森节、那达慕、丰年祭 | 2026/2027 官方日期 + 后续年份历法推算，均标为估算 |

每个选中地区各按**自己的当地日历日**（该地区 IANA 时区 + `Intl.DateTimeFormat`）取「今天」。展开各地区今年和明年的节日后合并，按「还有几天」排序取最近的一个；同天按日期、再按类别排。倒计时是相对该地区当地今天的纯日期差，出差或系统时区不同也不会差一天。

### 精度说明

- 公历固定、农历、星期规则、复活节在 `Intl` 支持的年份内是准确的。节气算法对照 2026 年历核对过：清明 2026-04-05、冬至 2026-12-22（北京时间 04:50，即 UTC 12/21 20:50）。
- 伊斯兰历按 Umm al-Qura 民用历计算，依观月确定日期的国家可能差一天。藏历、泰米尔历、佛历相关节日走年份表：2026 与多数 2027 是官方公告（西藏文旅厅与拉萨放假通告、中国西藏网、马来西亚 JPA 与首相署、新加坡 MOM、台湾行政院公报），其余 2027–2030 是第三方历法推算。这些节日在徽标和悬停里都带「约」，并提示以官方公告为准。
- 泼水节按惯用的 4/13（傣历新年节期是 4/13–15）；那达慕与原住民族丰年祭没有全国统一日期，用惯用的年中日期近似。三者都标「约」。
- 超出年份表时，有 fallback 规则的节日（卫塞节、那达慕、丰年祭）回落到估算日期；没有的直接隐藏，不编造。年份表每隔几年要更新一次。
- 只显示节日本身的日期，不计算补假／调休／observed date（美国联邦假日的观测日、英国银行假日补假、港澳台补假、马来西亚开斋节第二天等）。唯一例外是香港「節禮日」——法定是「圣诞节后第一个工作日」而非固定 12/26，按官方年份表处理。
- 除夕按「春节前一日」计算，不是腊月三十：连续几年农历腊月都没有三十日。
- 浏览器缺少 `chinese` / `islamic-umalqura` 历法时，跳过对应节日，只显示公历类节日。
- `localStorage` 不可用时，选择只在本次会话有效，选择器会说明。

## 安装

```sh
dsh plugin add dsh-next-festival
```

没出现就重启一次 DSH（Loader 行只在启动时读）。

在仓库根目录本地开发：

```sh
node scripts/install.mjs --profile desktop --apply
```

## 调整

| 想改什么 | 改哪里 |
| --- | --- |
| 节日清单、名称、规则 | `lib/client.js` 的 `FESTIVALS` |
| 年份表节日的公布日期 | 同一张表里的 `years` |
| 地区名称与时区 | `REGIONS` |
| 边距、吸附与拖拽行为 | `lib/client.js` 里的 `MARGIN`、`snapPosition`、`pixelsFromRatio` |
| 徽标尺寸、配色、类别颜色 | `css` 数组与 `KIND_COLORS` |
| 设置区布局 | `css` 数组里的 `.dsh-nf-row` 等 |
| 刷新频率 | 徽标组件里的 `setInterval(tick, 30000)` |

用软链开发安装时，改完 `lib/client.js` 刷新页面即可——客户端 bundle 直接从磁盘读取。

## 原理

徽标自己管理位置：`pointerdown/move/up` + `setPointerCapture`、`resize` 监听，吸附后写入共享 store 持久化。宿主半 `lib/index.js` 只留一个空 `apply`，存在的意义是让包成为 Loader 行，把 `dsh.client` 带进浏览器启动图。`lib/client.js` 注册两个槽：徽标用 `shell.overlay` 的独立 list entry，地区选择器进按包名索引的 `plugins.bundle.config`。它**不碰** `conversation.header.leading` —— 那是 `dsh-solar-term` 占用的 single 槽，两个插件不共用槽位。后一个槽只在插件页打开时由插件管理页面声明，`ctx.slots.inject` 会等它出现，不需要重启。
